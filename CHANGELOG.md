# Changelog

## 0.1.0

- Added source ranges, line/column conversion, diagnostics, and encoding
  marker detection.
- Added indentation-aware tokenization, Unicode identifiers, numeric and
  string literals, and PEP 701 f-string token boundaries.
- Added a CPython-shaped AST, core expression/statement parsing, comprehensions,
  pattern matching, recovery mode, visitors, validation, dump, unparse, and
  CLI commands.
